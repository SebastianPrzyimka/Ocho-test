# Photos

Put the owner's photos here (JPG, PNG, WebP or AVIF, ideally 2400px on the long side),
then set `file` for the matching entry in `src/content/photos.ts` to the file name.
The build makes small, fast AVIF/WebP versions automatically.

Only add photos Ocho owns or has permission to use. Do not copy photos from Google,
Tripadvisor, Facebook, Instagram or review sites.
